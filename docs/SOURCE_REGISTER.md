# Source Register — Mount Kei Reforestation Project

**Purpose.** This register records the public information used to understand the Mount Kei project, so that every
non-financial fact shown in the application can be traced. **No financial figure in the dashboard comes from these
sources.** All budgets, transactions, suppliers and forecasts are synthetic (see `FINANCIAL_LOGIC.md` §8).

Access date for all web sources: **11 November 2026**. Status key:
- **Confirmed**: stated by Hummingbirds or the project partners in their own publication.
- **Historical**: true when published; may since have changed.
- **Subject to change**: a target, projection or plan.
- **Third-party**: reported by a third party, not confirmed by Hummingbirds.

## 3. What the illustrative model takes from the sources

| Model element | Basis |
|---|---|
| Project name "Mount Kei Reforestation", country Uganda | S1, S2 |
| Expense categories (seedlings, nursery, land preparation, planting, community development, monitoring & verification…) | Activities described in S1/S2 (nursery and plantation roles, intercropping, VCS/CCB verification). The categories are **proposed**, not Hummingbirds' chart of accounts. |
| Local costs partly in UGX | Project location (Uganda). The FX rate is an illustrative planning rate. |
| Seasonal phasing (planting in the rainy season) | General assumption for West Nile. Not taken from a Hummingbirds source. |
| €2.4m FY2026/27 budget | **Fictional.** Chosen to be of a plausible order of magnitude next to the public phase-2 figure of €3m for 2024–25 (S5). It is not derived from it and should not be read as an estimate of actual spending. |

## 4. Verified facts vs assumptions vs synthetic data

- **Verified public facts:** partners (EFC, Form International), location (Mount Kei CFR, Koboko/Yumbe, West Nile),
  activity types, Verra VCS/CCB intention, operations since 2023.
- **Reasonable assumptions (labelled):** expense categories, seasonal phasing, use of UGX for local suppliers,
  a 12-month April–March budget phase.
- **Synthetic:** every amount, transaction, supplier name (all suffixed "(synthetic)"), invoice and document reference
  (`SYN-DOC-…`), forecast and assumption text.

## 5. Information gaps

- No public project budget, cost breakdown, chart of accounts or reporting calendar.
- No public information on Hummingbirds' internal financial reporting process, systems or approval thresholds.
- **Gondwana:** no source found linking Mount Kei to the Gondwana platform or portfolio. **The app does not assume
  such a link.**
- S4 mentions a planned sale of the project to a corporate buyer in 2026. Its current status is unknown.
- The Verra project ID was not confirmed on the Verra page itself. S6 gives 5090 (third-party).
- Land Matrix pages could not be fetched directly on the access date (empty response). Figures come from search
  extracts and should be re-verified.
